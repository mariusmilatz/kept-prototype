## Autonomous OpenCode workspace

This folder is an isolated duplicate created specifically for autonomous
OpenCode development.

OpenCode is authorized to:

- read and edit any file inside this project
- create or modify project-level AGENTS.md, skills, agents, commands, and
  opencode.json
- run builds, tests, linters, formatters, and local development servers
- create normal Git commits
- push normal commits to this project's configured `origin`
- create branches and pull requests when useful
- use GitHub CLI for this repository

OpenCode does not need separate approval for ordinary edits, commits, or pushes
inside this duplicate workspace.

- Never modify `/Users/mariusmilatz/Documents/Marius/Kept`
- Never push to `mariusmilatz/kept-prototype`
